# 内容与故事线

## 证据账本

每个准备放上页面的主张记录来源位置、原文性质、可说到什么程度、不能推出什么。至少区分：

- 材料直接报告的事实；
- 原作者的解释或讨论；
- 汇报者基于材料形成的解释；
- 尚需核对的内容。

数字、单位、样本量、显著性、因果用语、图号和页码必须回到当前材料核对。不同任务的作者、机构、期刊、年份、DOI 和数据不得从上一轮复制。

## 按场景组织

以下是可选组织方式，不是固定章节。先依据沟通目标和主材料选择；用户已写好的综述或报告优先延续其有效结构，不自动转换成原始论文精读。

- 已有综述转短报告：沿用报告的核心分类与范围，交代研究现状、代表进展和展望；原始论文用于核查，选取少量代表证据支撑综述，不让可用图片决定主线。
- 第三方论文讲解：为什么值得讲 → 问题 → 方法/比较 → 关键证据 → 结论边界 → 讨论。
- 作者会议报告：问题与缺口 → 方法或识别逻辑 → 最关键结果 → 贡献和边界 → 提问附录。
- 研究进展：目标与当前阶段 → 已完成证据 → 偏差/失败与解释 → 下一步决策。
- 开题：问题与价值 → 已知证据 → 缺口 → 研究问题 → 方法可行性 → 计划与风险。
- 答辩：遵守学校必要章节，同时把最重要的研究贡献与证据放在主线，程序性材料不挤压结果。

不要机械翻译论文目录，也不要把每个场景套入固定页数。

## 多篇比较

只有比较是沟通目标时才建立共同维度，例如问题、方法、证据或适用边界；维度数量由任务决定。多篇材料也可按分类、发展脉络、问题或逐篇精读组织。用户要求逐篇讲解时保留该顺序，在需要处补比较，不强制改成比较矩阵。相同研究对象使用稳定术语和颜色映射。

分类不自动意味着时间演进或因果递进。使用箭头、时间线或“从……转向……”前核对关系依据；只有并列关系时使用并列结构。

## 标题规则

- 证据页：需要突出发现时写有证据支持的结论句；需要章节定位时可用“章节—主题”，将发现放在正文或图注，不强制统一为结论标题。
- 方向页、地图页、程序性必需页：允许简短结构标题。
- 评价页：使用有边界措辞，如“可考虑”“在本研究条件下”“更适合解释……”。
- 标题串联后应能看出完整主线，但不能为了形式统一把每页都写成生硬口号。

页面计划完成后做一次标题串联检查：只读正文页标题，检查问题、方法、证据和结论是否存在逻辑跳跃。结构页不强制改成结论句；发现跳跃时优先修故事线或页面任务，不用口号掩盖缺口。

## 一页一个认知任务

一个页面承担一个主要沟通任务，但可容纳多个支撑元素。需要解释坐标、曲线或机制时为关键图留足空间；分类总览、应用概览和比较可并列多组图文。图的数量由用途、阅读负荷与可用版面决定，不设每页图数配额。先删减、拆页或调整布局，再考虑缩小字号。

每个关键素材都要回答两个问题：它为本页承担什么沟通任务，听众应从中看到什么关键发现。图表不支持页面主张、汇报时不会讲到或投影后无法读清时，移入附录、换用更合适素材或请求高清版本。

逐图核对原文图号、面板、仿真/实测属性、条件与指标；一篇论文包含实测，不代表其中任意图都是实测证据。概览也不得用不相符的图示暗示验证结果。内容可以通过文字、表格或原生示意结构讲清时，不强行寻找原图填充。

证据边界始终约束措辞，但不必占独立页面或栏目。用限定语、图注或讲稿表达必要条件；只有边界本身是汇报重点时才重点展开。压缩内容不得删掉会改变结论的条件。结论优先回应本次汇报问题，避免固定填写“研究格局—局限—空缺”。

## 时间预算

先扣除开场、结尾和提问，再按认知负荷分配时间。关键图表、方法链和比较页通常需要更久；封面和导航更短。时间不足时删去次要证据或移入附录，不通过堆叠图表或计划“讲快一点”解决。

## 个人表达边界

个人判断必须指向任务材料、用户观点或可核对的比较结果。没有依据时改为待讨论问题，不生成模板化“启示”和拔高结论。本 Skill 不处理论文批注，也不把批注截图列为必需输入。
