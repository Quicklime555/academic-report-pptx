# 内容与故事线

## 证据账本

每个准备放上页面的主张记录来源位置、原文性质、可说到什么程度、不能推出什么。至少区分：

- 材料直接报告的事实；
- 原作者的解释或讨论；
- 汇报者基于材料形成的解释；
- 尚需核对的内容。

数字、单位、样本量、显著性、因果用语、图号和页码必须回到当前材料核对。不同任务的作者、机构、期刊、年份、DOI 和数据不得从上一轮复制。

## 按场景组织

- 第三方论文讲解：为什么值得讲 → 问题 → 方法/比较 → 关键证据 → 结论边界 → 讨论。
- 作者会议报告：问题与缺口 → 方法或识别逻辑 → 最关键结果 → 贡献和边界 → 提问附录。
- 研究进展：目标与当前阶段 → 已完成证据 → 偏差/失败与解释 → 下一步决策。
- 开题：问题与价值 → 已知证据 → 缺口 → 研究问题 → 方法可行性 → 计划与风险。
- 答辩：遵守学校必要章节，同时把最重要的研究贡献与证据放在主线，程序性材料不挤压结果。

不要机械翻译论文目录，也不要把每个场景套入固定页数。

## 多篇比较

先建立 3–5 个共同维度，例如问题、样本/材料、方法、证据、适用边界和局限。按维度对齐论文，而不是“论文 A 摘要一遍、论文 B 摘要一遍”。相同研究对象使用稳定术语和颜色映射。

## 标题规则

- 证据页：优先写证据支持的结论句。
- 方向页、地图页、程序性必需页：允许简短结构标题。
- 评价页：使用有边界措辞，如“可考虑”“在本研究条件下”“更适合解释……”。
- 标题串联后应能看出完整主线，但不能为了形式统一把每页都写成生硬口号。

## 一页一个认知任务

一个页面只承担解释、比较、证明、定位、总结或提问中的一个主要任务。一个关键图表通常独占一页；只有“同时比较”本身是任务时才并列两个对象。先删减、拆页或调整布局，再考虑缩小字号。

## 时间预算

先扣除开场、结尾和提问，再按认知负荷分配时间。关键图表、方法链和比较页通常需要更久；封面和导航更短。时间不足时删去次要证据或移入附录，不通过堆叠图表或计划“讲快一点”解决。

## 个人表达边界

个人判断必须指向任务材料、用户观点或可核对的比较结果。没有依据时改为待讨论问题，不生成模板化“启示”和拔高结论。本 Skill 不处理论文批注，也不把批注截图列为必需输入。
