# 制作能力适配

## 原生 PPTX 能力

本 Skill 负责学术内容契约、模板策略和验收，不复制通用 PowerPoint 渲染引擎。

在 Codex 中若 `ppt-master` 可用：

- 从材料新建：使用 Generate PPTX；
- 把用户模板变成可复用系统：使用 Create Template 或 Generate PPTX 中的模板流程；
- 改善已有学术 PPTX：根据目标使用 Beautify 或 Edit Native PPTX；
- 遵守 `ppt-master` 自己的加载顺序、阻塞关卡和最终验收。

宿主没有 `ppt-master` 时，可使用其他能创建原生文字、形状、表格、图表和备注的 PPTX 能力，但必须保持同样的证据、模板、渲染和对象卫生要求。只有整页位图能力时，停止并说明无法满足“可编辑 PPTX”的核心承诺。
